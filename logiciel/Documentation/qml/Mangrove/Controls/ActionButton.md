# ActionButton

> QML · module `Mangrove.Controls` (generic) — [`ActionButton.qml`](../../../../qml/Mangrove/Controls/ActionButton.qml)

`IconToolButton` driven by an `AppAction`: icon, tooltip, checked state, enabled state and click come from the action.

## Properties

`appAction`: the action shown. It is not called `action`, a name already taken by Qt's
`AbstractButton`.
